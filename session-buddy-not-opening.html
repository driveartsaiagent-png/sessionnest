Session Buddy not opening or your sessions are missing?

Session Buddy keeps your saved sessions inside the extension on your computer. If it won't open, shows an empty list, or something changed after an update, try these steps in order. (We are not connected with Session Buddy — this is general advice from people who build tab managers.)

First: don't uninstall or reinstall Session Buddy. Removing an extension deletes the data it has stored. While it stays installed, your sessions may still be there.

1. Restart the browser once

Close every browser window and open it again. Sometimes an extension that just updated doesn't start until the browser restarts.

2. Check that it is turned on and up to date

  1. Type chrome://extensions in the address bar (Edge: edge://extensions).
  2. Find Session Buddy and make sure its switch is on. If Chrome shows a warning on it, read it — it says why the extension was stopped.
  3. Turn on Developer mode (top-right) and click Update to get the latest version. You can turn Developer mode off again after.

3. Check you're in the same profile

Each browser profile has its own Session Buddy data. If you opened a new profile or signed in with another account, your sessions are in the old profile.

4. As soon as it opens: save a backup file

Use Session Buddy's export or backup option (look in its settings or menu) and save the .json file somewhere safe — your Documents folder or a cloud drive. With this file your sessions can't be lost, whatever happens to the extension later.

5. If the sessions are really gone

  • Check Session Buddy's own help and support pages — the developer may have published recovery steps for a specific version.
  • Open the Chrome menu ⋮ → History → Recently closed to bring back the windows you closed most recently.
  • Press Ctrl+H to search your browser history for the pages you remember.
